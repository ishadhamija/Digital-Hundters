# 🎮 Digital Hundters — Mobile & XR Game Studio Landing Page

A sleek, sci-fi and cyberpunk-themed landing page developed as **Task 3** of the **Cohort 3.0** program at **Sheryians Coding School**.

## 🌐 Live Preview
- **Live Demo:** [https://digital-hundters.vercel.app/]

## ✨ Features
- **Hero Section:** High-impact sci-fi layout with call-to-action triggers and neon accents.
- **Metrics Bar:** Modern glassmorphism/transparent stat blocks highlighting studio achievements.
- **Projects Showcase:** Clean game cards featuring dynamic tags and multi-platform availability icons.
- **Development Roadmap:** Visual 5-step workflow breakdown from concept to launch.
- **Futuristic Footer:** Integrated socials, quick contacts, and glow effects.

## 🛠️ Tech Stack
- **Markup:** HTML5
- **Styling:** CSS3, Tailwind CSS (via CDN)
- **Icons:** Remix Icon
- **Typography:** Orbitron & Inter (Google Fonts)
